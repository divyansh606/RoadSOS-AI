About the Project:
RoadSOS AI is a smart emergency support system created to help people during road accidents. The main goal of this project is to reduce response time by quickly finding nearby hospitals and emergency services using live location tracking.

The platform provides:

* Live GPS location tracking
* Nearby hospital detection
* Emergency alerts
* AI voice assistance
* Real-time emergency support

Technologies Used:

* HTML
* CSS
* JavaScript
* Geolocation API
* OpenStreetMap
* Speech Recognition API

How to Run:
Open the index.html file in any browser to start the project.

Future Improvements:

* Live ambulance tracking
* AI accident detection
* Multi-language support
* Offline emergency alerts
